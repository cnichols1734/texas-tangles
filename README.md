# Texas Tangles Salon — Website

Professional one-page website for Texas Tangles Salon, Baytown's trusted hair salon since 1948.

## Tech Stack

- **HTML5** — Semantic, accessible markup
- **CSS3** — Custom properties, Grid, Flexbox, animations
- **JavaScript** — Vanilla JS for interactivity
- **Libraries (CDN):** Font Awesome 6, AOS (Animate on Scroll), Google Fonts

## Deployment

Hosted on **Cloudflare Pages**. Push to `main` to deploy.

## Features

- Elegant, timeless salon aesthetic
- 77-year heritage timeline
- Services grid with hover effects
- Review slider with swipe support
- Google Maps embed
- Mobile-responsive with click-to-call
- SEO optimized with structured data
- Scroll reveal animations
- Today's hours highlighted automatically
